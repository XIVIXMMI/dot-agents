# dot-agents

My dotfiles for AI coding tools: reusable configs, agents, rules, and skills, one folder per tool.

| Folder | Tool | What it holds |
|---|---|---|
| [`claude/`](claude/) | Claude Code | Stack-neutral subagent team, rules, skills, and a TDD feature pipeline with owner gates |

Each folder mirrors what you put in a project (or `~`): copy or symlink it, then fill in the placeholders. Add a folder per tool (`codex/`, `cursor/`, ...) as needed.

Third-party material is credited in `THIRD-PARTY-NOTICES.md`.
