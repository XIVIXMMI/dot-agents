# specs/

Per-feature specs, written in order by the agents of the `new-feature` pipeline.
Naming (kebab-case): `<feature>.md` (UX spec), `<feature>-tech.md` (technical design), `<feature>-tests.md` (test cases). `architecture.md` is written once per project. Keep each file about 150 lines or less.

Templates: `_template-feature.md`, `_template-tech.md`, `_template-tests.md`, `_template-architecture.md`. Copy and rename; do not edit the templates for one project.
