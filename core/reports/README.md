# reports/

One-off outputs of agents. Not needed to build a feature; read only when you need the history. Keep short but complete.

| Template | Written by | Purpose |
|---|---|---|
| `_template-dev-report.md` | developer | What changed per feature and why, deviations from spec |
| `_template-test-report.md` | tester | Final verification: runs, results, failures, expected failures |
| `_template-audit.md` | sec-perf-reviewer / tester | Read-only traceability audit: spec vs implementation vs tests |
| `_template-research.md` | product-strategist | Advisory research that answers an [Open] decision |
| `_template-bugs.md` | any | Running bug list `bugs.md` (BUG-NNN, priority, status) |
| `_template-night-log.md` | orchestrator | Log of delegated, unattended work with a morning summary |
