# presets

A preset is a project's recipe. `example/` is a sample only: copy it to `presets/<your-project>/` and edit.

- `components`: which `core`, `stacks/*`, `workflows/*` folders to install.
- `CLAUDE.md`: skeleton with placeholders for the project's context, structure and commands.
- `settings.json`: sample permissions and hooks (Swift / Xcode flavoured).
