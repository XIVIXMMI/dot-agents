# workflows/tdd-pipeline

The TDD agent pipeline: 6 agents (strategist, UX, architect, tester, developer, reviewer), `new-feature` skill, `workflow.md` and `testing.md` rules, and `specs/` + `reports/` templates.
Depends on `core` (decision log, docs). Another way of building goes in a sibling folder, e.g. `workflows/spec-first/`.
